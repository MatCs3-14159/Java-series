# Java-series
This sequence will take you from university-level Java to the skills expected of many professional Java backend developers.

# Java Developer Roadmap: Beginner to Professional (18–24 Months)

## Goal

Become a professional Java developer capable of building:

- Enterprise applications
- REST APIs
- Database-driven systems
- Spring Boot applications
- Microservices
- Cloud-ready systems
- Production-level software
